# PaperResearch v2 technical closeout

PaperResearch v2 is closed. Real multimodal Agent integration was implemented and exercised, while independent scientific report quality did not meet all preregistered requirements. This release packages that engineering result honestly rather than presenting a reliable automatic researcher.

## Delivered engineering

The existing ResearchAgent Runner, rule Planner, tools, Checkpoint and source representation were reused. PDF-native text, tables, equations and CLIP evidence can reach the Agent; compatible Providers receive actual PDF image media with source identity. Goal-aware evidence assembly records roles, selection, budgets and missing coverage. Generated drafts pass Schema, source/citation and visual-binding checks and remain UNVERIFIED.

Semantic review preserves claims, precise evidence spans, reasons and four possible outcomes. Strict publication keeps real HumanApproval, scope, atomicity, visual review, source identity and digest gates. No second Agent, evidence graph, retrieval system or automatic approval layer was added.

## Scientific results

[Case results](cases.md) record COCO-LM source-audited delivery and **FAIL** for FNO and U-NO independent scientific acceptance. U-NO's offline citation-only derivative does not replace either INCOMPLETE original run. A source hash or exact citation proves identity, not semantic entailment.

The independent 117-case automatic-verifier evaluation failed its frozen A-layer qualification: false SUPPORTED 4/66, one-sided 95% upper bound 13.33%; SUPPORTED precision 37/41, lower bound 79.05%; contradiction recall 34/43; accuracy 88/117. Subsequent v4/v4-r2 work used known development cases and did not confer independent qualification. PARTIAL, PDF-native formula/visual understanding and full automatic trusted publication remain unqualified.

## Principal limitations

Evidence role labels do not reliably measure substantive context completeness. U-NO's memory-plot caption matched architecture vocabulary while the architecture evidence was omitted; inference costs were recalled but discarded. Formula/table extraction can split subscripts, headers or conditions. Generation and full-prose claim registration still lose conditions and make errors. Complete visual media transport does not certify correct observation or complete ROI grounding.

See [known limitations](known_limitations.md), [architecture](architecture.md) and [usage](usage_guide.md). No further paper, algorithm, model training or experiment was added for this release.

## Recorded cost and scope

The closeout ledger recovered 10 model-task receipt groups totaling 144 paid HTTP requests, approximately $0.1514064 under each receipt's peak all-cache-miss estimate. This is not an invoice or total lifetime project cost. Earlier work, local hardware/electricity/storage and all previous model downloads were not exhaustively priced. U-NO's two requests were separately recorded at approximately $0.0059739 and $0.0074427. Image tokens were not separately itemized.

U-NO native preparation recorded 160 model input records and approximately 354.802 seconds, including about 239.448 seconds document embedding and 9.486 seconds CLIP. Preparation is not per-query latency. The final citation normalization/closeout and this GitHub packaging task made no new model requests.

## Public distribution

Only the necessary source/config/test/document subset is published. Local scientific artifacts, PDFs, images, requests, traces, checkpoints, models and databases remain excluded. The release branch starts from the already-public main; the additional 150 private development commits (1120 unique blobs/about 358.5 MB) are not ancestors of the release commit.

Core `src/` files preserve the closed-out implementation; the sole source formatting difference removes an extra blank line at the end of indexing/service.py. Packaging-only differences are listed in [reproducibility](reproducibility.md): relocatable Phase4 helper root, removal of cached machine observations from the distributed model manifest, Docker context repair, environment examples and optional dependency declarations. Historical sources/manifests/results were not changed.

The release inventory and observed checks are in [release_manifest.json](release_manifest.json) and [release_checks.md](release_checks.md). Server model aliases do not prove immutable weights. No automatic verifier qualification or strict trusted publication is granted by this release.
