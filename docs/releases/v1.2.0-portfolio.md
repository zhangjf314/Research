# PaperResearch v1.2.0-portfolio

`v1.2.0-portfolio` is a portfolio release for explicit Workflow/Research Agent
UI modes, Agent final-report synthesis, public documentation truth alignment,
and cross-platform CI maintenance.

Release status:

```text
RELEASED_WITH_DOCUMENTED_LIMITATIONS
```

## What's new

### Workflow / Research Agent UI modes

The UI now exposes two explicit research execution modes:

- Workflow: the predefined Deep Research Workflow path.
- Agent: the state/observation-driven Research Agent path.

For backward compatibility, Workflow is preselected when no mode parameter is
provided.

### Research Agent final-report synthesis

The Research Agent can now synthesize a user-facing final report after:

```text
Agent execution
-> verification PASS
-> Agent control loop ends
-> final-report synthesis
-> report validation/compiler
-> Markdown report
```

The final-report stage uses verified Evidence State only. It is not an Agent
tool, planner action, retrieval call, or replan behavior.

### API additions

Agent responses add report-related fields such as:

- `report_status`
- `report_markdown`
- `report_available`
- `report_failure_reason`
- `report_usage`
- `report_provider_requests`
- `report_claim_count`
- `report_citation_count`
- `report_evidence_references`

These are additive fields. Existing Agent execution status and verification
state remain separate from report status.

### Documentation and CI

- Public architecture documentation now separates shared RAG, Deep Research
  Workflow, and Research Agent runtime.
- README links and portfolio materials were updated for v1.2.0.
- Linux CI portability and GitHub Actions runtime maintenance were completed.

## Evaluation evidence

The official Workflow-vs-Agent benchmark remains the frozen v1.1.0 Stage 4
artifact. This release does not rerun Stage 4 and does not reinterpret those
metrics.

## Historical benchmark boundary

- Stage 4 benchmark runtime = frozen v1.1.0 runtime evidence.
- Agent final-report synthesis was not part of Stage 4.
- Dual-mode UI was not part of the Stage 4 benchmark.
- `effective_replan_count=0` remains unchanged.
- R1-R4 provider-schema reliability patches are not merged into this release.

## Known limitations

- Deep Research Workflow synthesis remains subject to stochastic
  provider/schema/report-quality failures under strict validation.
- This release does not claim commercial production reliability.
- Stage 4 benchmark evidence predates Agent final-report synthesis.
- Effective live replanning was not observed in the frozen benchmark.
- No strong semantic grounding, large-scale strict blind generalization, or
  hallucination-elimination claim is made.

## Release verification

Release verification consists of local release gates, release-branch CI, main
CI, annotated tag verification, and GitHub Release creation. No provider,
embedding, reranker, Workflow live, Agent live, Deep Research, or benchmark run
is performed during the release process.
