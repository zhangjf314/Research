# PaperResearch v1.1.0-portfolio

`v1.1.0-portfolio` is the recommended portfolio release after the Research
Agent benchmark line was frozen and audited.

## Added

- Research Agent v1 runtime with explicit state, evidence state, dynamic tool
  selection, verification-before-finish, checkpoint/resume, retry bounds,
  budget limits, stop conditions, and trace.
- Frozen Workflow vs Agent paired benchmark over 60 internally authored and
  reviewed research tasks.
- Stage 4C final validity audit, metric provenance, claim-boundary, and release
  readiness artifacts.
- Portfolio summary, interview notes, release status, and final facts documents
  for public review.

## Changed

- Package/runtime version is `1.1.0+portfolio`.
- Display/tag version is `1.1.0-portfolio`.
- README now positions the repository around engineering closure and auditable
  evidence without the removed personal job-seeking sentence.

## Benchmark result

- Workflow: 0/60 completed, 60 failed.
- Agent: 56/60 completed, 4 failed.
- Agent structured W/T/L: 56 wins, 4 ties.
- Workflow provider requests/tokens/cost: 73 / 159,769 / `$0.03092796`.
- Agent provider requests/tokens/cost: 414 / 414,569 / `$0.06447728`.

## Boundaries

- The benchmark is internally authored and reviewed.
- It is not a public benchmark and not a strict blind generalization benchmark.
- It is not a strict equal-budget causal ablation.
- Structured proxy metrics are valid; full semantic content-level rubric
  validation was not completed.
- No effective live replan was observed in the final benchmark.
- Existing tags `v1.0.0-portfolio` and `v1.0.1-portfolio` are retained.
